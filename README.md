# 贪吃蛇 · Snake

使用 **C++ 和 EasyX 图形库**编写的贪吃蛇小游戏，包含蛇身移动、随机食物、吃食物增长和暂停控制。通过一个源文件展示图形绘制、键盘输入与游戏循环的基本实现。

## 功能

- **图形窗口**：640 × 480，使用圆形绘制蛇身和食物。
- **方向控制**：支持 WASD 和方向键，禁止直接切换到当前移动方向的反方向。
- **吃食物增长**：吃到食物后增加一节蛇身，并重新生成食物。
- **随机食物**：随机生成位置与半径，半径范围为 5～14 像素。
- **边界穿屏**：到达窗口边界后，从另一侧继续移动。
- **暂停与继续**：按空格暂停，再按空格继续。
- **批量绘图**：使用 EasyX 的批量绘图接口刷新画面。

## 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows |
| 编程语言 | C++ |
| 开发方式 | Visual Studio，安装“使用 C++ 的桌面开发”工作负载 |
| 图形库 | [EasyX](https://easyx.cn/) |

程序使用 `graphics.h`、`conio.h` 和 Windows 接口，需要先配置 EasyX，不能仅靠标准 C++ 编译环境运行。[EasyX 安装说明](https://docs.easyx.cn/zh-cn/setup)

## 编译与运行

1. 安装 Visual Studio 和 C++ 开发工具。
2. 下载并安装 [EasyX](https://easyx.cn/)，为使用的 Visual Studio 版本安装对应支持。
3. 在 Visual Studio 中创建 **C++ 空项目**。
4. 在“源文件”上右键，选择“添加 → 现有项”，添加本仓库的 [`贪吃蛇.cpp`](贪吃蛇.cpp)。
5. 编译项目，按 **Ctrl + F5** 运行。

如果提示找不到 `graphics.h`，请检查 EasyX 是否已安装到当前使用的 Visual Studio 环境。

## 操作说明

| 按键 | 操作 |
| --- | --- |
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `Space` | 暂停 / 继续 |

WASD 支持大小写。游戏开始时蛇身长度为 3，默认向右移动。

## 代码结构

项目的主要逻辑集中在一个源文件中：

| 函数 | 作用 |
| --- | --- |
| `GameInit()` | 创建窗口，初始化蛇身、方向与食物 |
| `GameDraw()` | 清空画面并绘制蛇身和食物 |
| `snakeMove()` | 更新蛇身位置，处理边界穿屏 |
| `keyControl()` | 读取方向和暂停输入 |
| `EatFood()` | 判断是否吃到食物，增加长度并生成新食物 |
| `Snakedie()` | 自碰撞判断函数，当前未接入主循环 |
| `main()` | 组织游戏循环，并通过 `Sleep(100)` 控制更新节奏 |

## 当前实现范围

当前版本以基础玩法演示为主，没有计分、难度选择、游戏结束或重新开始界面。`Snakedie()` 尚未在主循环调用，因此当前不会因撞到自身而结束游戏。

蛇身坐标数组容量为 `SNAKE_NUM = 500`，现有增长逻辑尚未增加容量检查。这是源码当前的实现边界。
